# V1 to V2

V1 is immutable Sepolia history: single canonical text, Color Font v1, its original registered spec, deployed addresses, and token rendering. Never reinterpret V1 tokens using V2.

V2 is a fresh contract/protocol release with exact prompt and Agent lines, Agent-line uniqueness, independently cycled 512/512 interleaving, packed 128-byte field, a new renderer identifier, and explicit protocol-release binding.

Read identity is always `chainId + contractAddress + tokenId`. A fresh V2 contract may restart token IDs without colliding with V1.
