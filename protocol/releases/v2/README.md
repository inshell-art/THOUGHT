# Binary-weave attempt — historical, unpublished

This directory is retained as exact development evidence for the earlier
binary-weave/visible-Unicode attempt. Despite its historical `v2` filenames
and identifiers, it was never approved, registered, published, or deployed as
a THOUGHT protocol release.

It is not the current V2 source of truth and must not be used for new contract,
renderer, provenance, metadata, deployment, or consumer work.

The current THOUGHT V2 implementation candidate begins at
`protocol/current/v2/README.md`. No THOUGHT V3 release is created by that work.
