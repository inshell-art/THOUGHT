# ThoughtNFT V2 Conformance Interface

Public product name: `THOUGHT`

The unversioned `ThoughtNFT` constructor pins PATH, the exact-spec registry, the immutable `ThoughtRenderer`, `ThoughtSpecRegistryV2`, one registered `protocolReleaseId`, and one immutable `CreationAttestationVerifier`. Construction verifies contract code, the expected `RENDERER_ID_HASH`, the expected creation-attestation profile ID, and release registration. Mint remains permissionless and consumes exactly one PATH `THOUGHT` unit.

The contract validates exact prompt, Agent, declared-Agent, and declared-model strings plus provenance, validates the supplied registered spec pair, derives packed field and all hashes from the prompt and Agent only, rejects an existing `agentIdentityHash` or `workHash`, classifies and verifies the optional creation-attestation proof using that same pair, consumes PATH, stores that same pair and all other immutable facts, safe-mints ERC-721, and emits events in that order. The constructor does not pin one spec version; multiple registered `THOUGHT.vN.md` versions may coexist and remain mintable.

`MintThoughtInput.declaredAgent` and `MintThoughtInput.declaredModel` are exact typed 1-through-64-byte safe single-line values validated before PATH consumption. `declaredAgentOf` and `declaredModelOf` expose the stored bytes. Canonical attributes are exactly Prompt, Agent Response, Declared Agent, Declared Model, Creation Attestation, and Texture Density in that order. `Protocol` and `Binary Contrast` are not front attributes. Exact `loomWeight`, `bitDistance`, and immutable protocol release facts remain ordered technical properties.

`MintThoughtInput.creationAttestation` contains only `runIdHash`, `deadline`, `authorityEpoch`, and a 65-byte signature. The canonical all-zero/empty proof skips the verifier and stores digest zero (`Unattested`). Any partial empty proof reverts. For a nonempty proof, `ThoughtNFT` constructs the complete EIP-712 claim from current contract and mint facts, calls the immutable verifier before PATH consumption, stores only its nonzero digest, and emits the attested-mint event. No proof nonce is consumed; Agent-line uniqueness is the post-success replay barrier.

The verifier profile is `inshell.thought.creation-workflow-attestation.v1`. Its exact EIP-712 domain name/version are `Inshell THOUGHT Creation Attestation` and `1`. The claim fields are `profileId`, `thoughtNft`, `protocolReleaseId`, `thoughtSpecId`, `thoughtSpecHash`, `workHash`, `provenanceHash`, `declaredAgentHash`, `declaredModelHash`, `runIdHash`, `intendedMinter`, `deadline`, and `authorityEpoch` in that order. The selected pair comes from the same validated mint fields used for registry validation and storage; it is not duplicated in the proof. Owner-only pause changes emit old/new pause state; owner-only authority rotation emits old/new authority and epoch and increments the epoch once. Two-step ownership is required. Pause and rotation block only future nonempty proofs; empty-proof minting and historical token metadata remain unchanged.

Read helpers expose exact packed field, `binaryFieldKeccak256`, `agentIdentityHash`, `workHash`, both declarations, attestation digest, registry/release/manifest bindings, frozen renderer/work/attestation profile hashes, `svgOf`, and marketplace `tokenURI`. The contract computes and passes authoritative stored facts to the pinned renderer. Declarations and attestation do not affect lines, hashes, Agent uniqueness, packed field, SVG, or work identity. The contract does not prove Agent authorship, model identity, one-round process truth, or opaque provenance semantics.
