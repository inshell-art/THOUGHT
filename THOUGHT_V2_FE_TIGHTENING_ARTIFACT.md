# THOUGHT Artifact Handoff

This is the current frontend artifact contract for public THOUGHT work. `thought-v2` remains only in technical file paths and renderer identifiers.

## Consumer Rule

Fetch `artifacts/thought-v2/latest.json` or a pinned channel, fetch its manifest, and verify every file SHA-256 before use. Production consumers must pin an immutable `artifact_id` and hashes.

Do not reproduce the token image with frontend CSS. The official SVG is generated by `ThoughtNFT.tokenURI()` with renderer id `thought.svg.v2.fixed-a-32`. Use the downloaded/generated SVG as the work image.

## SVG Contract

The SVG is exactly:

```text
width="960"
height="960"
viewBox="0 0 960 960"
```

Top level:

```xml
<svg ...>
  <rect id="canvas-bg" width="960" height="960" fill="#050505"/>
  <g id="binary-background">...</g>
  <text ...>agentLine</text>
  <text ...>promptLine</text>
</svg>
```

There is no outer work frame, no `work-canvas` scale wrapper, no agent rectangle, and no prompt rectangle. The binary circles are cleared only inside the text areas so the two visible lines remain legible.

## Binary Field

- Renderer: `thought.svg.v2.fixed-a-32`
- Source order: UTF-8 `promptLine` bytes, then UTF-8 `agentLine` bytes.
- Capacity: exactly 1024 bits in a 32x32 matrix.
- Short data: repeat cyclically to capacity.
- Long data: truncate after bit 1024.
- `1`: filled canonical-green circle `#006100`.
- `0`: hollow canonical-green circle, `fill="none"`, `stroke-width="1"`.
- Matrix: `x=32`, `y=32`, `width=896`, `height=896`, cell size `28`, radius `10`, opacity `1.00`.
- Cleared text cells: `132`; visible bit positions: `892`.
- Hollow zero rings are emitted once as `binary-zero-pattern`; the contract overlays explicit `binary-one` circles only for visible one bits. The two canvas-colored clear rectangles remove the pattern beneath text without adding a visible frame. This is `static-pattern-with-one-overlays` with `canvas-color-text-rectangles` in the machine render contract.

The contract exposes the exact derived field with `binaryField(promptLine, agentLine)` and `binaryFieldOf(tokenId)`. Frontend provenance must use this exact result rather than reimplementing a different byte or fill rule.

## Visible Lines

Both lines use the project font stack, `text-anchor="middle"`, and `dominant-baseline="middle"`.

| Line | Text anchor | Clear area | Base/min font | Target width | Fill |
| --- | --- | --- | --- | --- | --- |
| Agent | `x=480`, `y=420` | `x=93`, `y=373`, `774x74` | `118 / 48` | `820` | `#f4f4f4` |
| Prompt | `x=480`, `y=830` | `x=149`, `y=821`, `662x46` | `34 / 18` | `820` | `#b8b8b8` |

Default canvas is `#050505`. The active contract preserves case and visible UTF-8 text; it does not uppercase or normalize the line content.

## Long Text

When an estimated text width exceeds the target width, the contract reduces the font size down to the line minimum and emits `textLength="820" lengthAdjust="spacingAndGlyphs"`. It does not emit a carousel or SVG animation. Short lines remain centered at their base font size.
